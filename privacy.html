Privacy Policy

NWI Automated Backups

Last updated: October 3, 2026

Purpose

NWI Automated Backups is a private backup utility operated by the owner of NWI CONNECT. It is intended for internal backup and recovery use, with no public registration. This policy applies to this utility.

Google Drive access

The operator authorizes Google Drive access through Google OAuth. Within the permissions granted, the utility uses file and folder metadata and backup file contents to locate, upload, verify, retrieve, and manage backup files. These data are used only for backup and recovery operations.

Storage and protection

Backup archives are intended to be encrypted before upload to the operator's Google Drive account. OAuth credentials and encryption keys must be kept in private configuration or secret storage, outside this public information website. Backup retention is controlled by the operator.

Sharing and service providers

Google Drive hosts the uploaded backup files. When GitHub Actions is used, backup data are processed temporarily during the backup workflow. Google and GitHub process data under their respective terms and privacy policies. The utility does not sell Google user data or use them for advertising or training AI models.

Revocation and deletion

The operator can revoke authorization through the Google Account connections page and remove stored OAuth credentials from the backup configuration. Revoking access does not automatically delete existing backups. The operator can delete those files from Google Drive and empty the trash, and remove any separately retained local copies.
